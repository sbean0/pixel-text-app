# Pixel Text Generator

A simple web app that converts user-input text into a large, pixelated font, perfect for t-shirt designs or other creative projects. Built with HTML, CSS, and JavaScript, and deployed on GitHub Pages.

## Features
- Enter custom text (up to 20 characters).
- Generate a pixelated output on a canvas.
- Download the result as a PNG file.

## How to Use
1. Open the app in your browser.
2. Type your text in the input field.
3. Click "Generate" to see the pixelated version.
4. Click "Download as PNG" to save the image.
